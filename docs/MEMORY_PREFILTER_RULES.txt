Jev 自动 Memory 初筛规则
========================

目标
----
程序只负责清理明显噪声，不负责判断一条消息是否值得长期保存。
清理后的正文交给大模型判断；原文只用于本地日志和追溯。

处理流程
--------
1. OCR 获取原始消息。
2. 程序识别空消息、纯噪声、纯颜文字和明显 OCR 噪声。
3. 只清理句首/句尾的安全语气壳。
4. 保留清理后的正文。
5. 清理后为空则丢弃；否则交给模型判断是否保存。
6. 模型确认后才总结、去重、冲突检查并写入 RAG。

可清理的句首/句尾安全语气壳
----------------------------
哈哈、哈哈哈、哈哈哈哈、嘿嘿、嘻嘻、呵呵、笑死、笑死我了、
嗯嗯、哦哦、呃、额、哎呀。

谨慎词
------
嗯、哦、啊、哎、呀、不是、就是、那个、这个、你知道吧。
这些词不能在正文中直接删除，避免改变否定、转折或指代含义。

可直接忽略的整条消息
--------------------
空白、只有标点、只有表情、只有颜文字、只有重复字符、
嗯、哦、好、好的、行、收到、知道了、明白、哈哈、哈哈哈、
嘿嘿、嘻嘻、笑死、问号、感叹号、省略号。

颜文字处理
----------
整条只有颜文字：丢弃。
正文和颜文字混合：删除颜文字，保留正文。
例如“我喜欢这个牌子(๑•̀ㅂ•́)و✧”保留为“我喜欢这个牌子”。

不能直接过滤的内容
------------------
喜欢、不喜欢、讨厌、习惯、不能、不要、介意、以前、小时候、
养过、计划、约定、生日、工作、家人等可能构成事实、偏好、边界、
经历或计划的词。它们交给模型判断。

注意
----
“哈哈，我很喜欢这个牌子”不能整条丢弃，只清理开头的“哈哈”。
“我不是不喜欢，只是现在没时间”不能删除“不是”。
敏感信息（密码、验证码、API key、支付信息等）不得写入长期 RAG。
